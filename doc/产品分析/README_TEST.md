## 🔧 功能说明

### 1. 产品创建和图片上传

- 创建产品后会自动上传测试图片
- 图片上传到阿里云OSS
- 返回图片URL用于后续操作

### 2. 成分提取和分析

- 需要真实的产品图片
- 图片尺寸必须大于10x10像素
- 使用AI模型识别产品成分
- 分析成分的安全性和功效

### 3. 产品列表获取

- 获取用户的所有产品
- 包含产品的基本信息和评分
- 支持按标签筛选

### 4. 产品冲突检测

- 选择至少2个产品进行冲突分析
- 检测成分间的冲突
- 提供使用建议和护肤步骤

## ⚠️ 注意事项

1. **图片要求**:
   - 必须使用真实的产品图片
   - 图片尺寸必须大于10x10像素
   - 建议使用清晰的产品成分表图片

2. **测试顺序**:
   - 成分提取需要先上传图片
   - 成分分析需要先提取成分
   - 冲突检测需要产品有成分列表

3. **Token管理**:
   - Token会过期，需要重新登录
   - 所有API都需要认证Token

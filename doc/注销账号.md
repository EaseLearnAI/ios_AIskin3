# 账号注销API文档

## 概述

账号注销功能允许用户彻底删除自己的账号及所有相关数据。此操作不可逆，会永久删除以下所有数据：

- 用户账号信息
- 所有护肤产品记录
- 所有护肤方案（Plan）
- 所有打卡计划（CheckinPlan）
- 所有广场方案（SquarePlan）
- 所有皮肤分析记录（SkinAnalysis）
- 所有成分冲突分析（Conflict）
- 所有用户反馈（Idea）

## API端点

### 删除账号

永久删除当前登录用户的账号及其所有相关数据。

- **URL**: `/api/users/delete-account`
- **方法**: `DELETE`
- **认证要求**: 必须（需要JWT Token）
- **请求体**: 无

#### 请求头

```http
Authorization: Bearer YOUR_JWT_TOKEN
```

#### 成功响应

- **状态码**: 200 OK
- **响应内容**:

```json
{
  "success": true,
  "message": "账号已成功注销，所有相关数据已删除",
  "data": null
}
```

#### 错误响应

**未认证**
- **状态码**: 401 Unauthorized
- **响应内容**:

```json
{
  "success": false,
  "message": "You are not logged in. Please log in to access this resource."
}
```

**服务器错误**
- **状态码**: 500 Internal Server Error
- **响应内容**:

```json
{
  "success": false,
  "message": "注销账号失败",
  "error": "错误详细信息"
}
```

## 前端调用示例

### JavaScript (Axios)

```javascript
const deleteAccount = async () => {
  try {
    const token = localStorage.getItem('token'); // 从本地存储获取token
    
    const response = await axios.delete('http://localhost:5000/api/users/delete-account', {
      headers: {
        'Authorization': `Bearer ${token}`
      }
    });
    
    console.log(response.data.message);
    // 删除成功后，清除本地token并跳转到登录页
    localStorage.removeItem('token');
    window.location.href = '/login';
  } catch (error) {
    console.error('删除账号失败:', error.response?.data || error.message);
  }
};
```

### JavaScript (Fetch API)

```javascript
const deleteAccount = async () => {
  try {
    const token = localStorage.getItem('token');
    
    const response = await fetch('http://localhost:5000/api/users/delete-account', {
      method: 'DELETE',
      headers: {
        'Authorization': `Bearer ${token}`,
        'Content-Type': 'application/json'
      }
    });
    
    const data = await response.json();
    
    if (data.success) {
      alert(data.message);
      localStorage.removeItem('token');
      window.location.href = '/login';
    } else {
      alert('注销失败: ' + data.message);
    }
  } catch (error) {
    console.error('删除账号失败:', error);
  }
};
```

```vue
  }
};
```


## 技术实现细节

### 事务支持

账号删除操作使用 MongoDB 事务确保数据一致性：

1. 开始事务
2. 依次删除所有关联数据：
   - Products
   - Plans
   - CheckinPlans
   - SquarePlans
   - SkinAnalysis
   - Conflicts
   - Ideas
   - User
3. 提交事务（所有操作成功）或回滚事务（任何操作失败）

### 删除顺序

数据删除按以下顺序进行：

1. Product（产品）
2. Plan（护肤方案）
3. CheckinPlan（打卡计划）
4. SquarePlan（广场方案）
5. SkinAnalysis（皮肤分析）
6. Conflict（成分冲突）
7. Idea（用户反馈）
8. User（用户账号）

## 安全注意事项

1. **认证检查**: 必须提供有效的JWT Token
2. **权限验证**: 用户只能删除自己的账号
3. **操作不可逆**: 删除操作无法撤销
4. **前端确认**: 建议在前端实现二次确认对话框
5. **数据备份**: 重要数据建议在删除前提醒用户导出

## 最佳实践

### 前端实现建议

1. **二次确认**: 使用确认对话框防止误操作
2. **加载状态**: 显示删除进度，防止重复提交
3. **错误处理**: 提供友好的错误提示
4. **自动登出**: 删除成功后自动清除token并跳转
5. **数据导出**: 提供删除前导出数据的选项

```vue
<script setup>

import axios from 'axios';

    const token = localStorage.getItem('token');

  } finally {
    isDeleting.value = false;
    showDeleteDialog.value = false;
  }
};
</script>
```


          
**实现概述**
- 路由保护与入口：所有护肤方案相关接口都要求登录后访问，统一在路由层挂载鉴权中间件，保证请求里可取到当前用户信息
- 数据聚合：生成方案时会汇总用户资料、已添加的产品清单、最近一次皮肤分析结果，并考虑女性用户的生理周期信息
- AI生成：把以上信息组织成严格的 JSON 输出提示词，将请求发给通义千问的兼容模式接口，返回的内容必须是可解析的 JSON
- 方案入库与步骤状态：对晨、晚各步骤自动补全 `completed:false` 字段并保存到数据库；提供接口更新某一步的完成状态；每天 0 点通过定时任务重置所有方案的完成状态

**实现细节与使用要点**
- 生成方案依赖产品列表：若用户没有任何产品将返回 400（`/controllers/planController.js:29-34`）
- AI返回必须是完整 JSON；控制器会尝试 `JSON.parse` 并在失败时返回 500（`/controllers/planController.js:152-167`）
- `completed` 字段在入库时强制补齐为 `false`，避免模型遗漏（`/controllers/planController.js:169-173`）
- 步骤更新严格校验 `period ∈ {morning, evening}` 并按 `step` 查找对应项更新（`/controllers/planController.js:301-331`）
- 每天重置完成状态由定时任务统一执行（`/server.js:38-54`），确保打卡逻辑回归

### 2. 创建产品

**API端点**: `POST /api/products`

**请求头**:
- `Authorization: Bearer {token}`
- `Content-Type: application/json`

**请求体**:
```json
{
  "name": "产品名称",
  "description": "产品描述",
  "label": "洁面"
}
```

**响应示例**:
```json
{
  "success": true,
  "message": "产品创建成功",
  "data": {
    "product": {
      "_id": "69144ff6dd21c35dfc15e01f",

      "label": "洁面",
      "ingredients": [],
      "imageUrl": "",
      "createdBy": "685ceb462cfa9bca020a338b"
    }
  }
}
```

### 3. 上传产品图片

**API端点**: `POST /api/products/{productId}/upload-image`

**请求头**:
- `Authorization: Bearer {token}`
- `Content-Type: multipart/form-data`

**请求体**: 
- 使用 `multipart/form-data` 格式
- 字段名: `productImage`
- 文件类型: 图片文件（jpg, png等）

**响应示例**:
```json
{
  "success": true,
  "message": "产品图片上传成功",
  "data": {
    "imageUrl": "http://abc1567849.oss-cn-beijing.aliyuncs.com/..."
  }
}
```

**注意事项**:
- 图片尺寸需要满足模型要求（高度和宽度必须大于10像素）
- 建议使用真实的产品图片进行测试

### 4. 提取产品成分

**请求头**:
- `Authorization: Bearer {token}`
- `Content-Type: application/json`

**请求体**: `{}`

**响应示例**:
```json
{
  "success": true,
  "data": {
    "name": "提取的产品名称",
    "ingredients": ["成分1", "成分2", "成分3"],
```

**注意事项**:
- 需要先上传产品图片

## 📝 完整流程示例

### 产品分析完整流程

1. **登录** → 获取Token
2. **创建产品** → 获取产品ID
3. **上传产品图片** → 获取图片URL
4. **提取产品成分** → 获取成分列表
5. **分析产品成分** → 获取分析结果

### 冲突检测流程

1. **登录** → 获取Token
2. **获取用户产品列表** → 选择至少2个产品
3. **分析产品冲突** → 获取冲突分析结果

## 🔧 Swift实现要点

### APIClient.swift
- 已实现完整的HTTP请求封装
- 支持GET、POST、PUT、PATCH、DELETE方法
- 支持文件上传（multipart/form-data）
- 自动添加认证Token
- 详细的日志输出

### ProductApiService.swift
- `createProduct()` - 创建产品
- `uploadProductImage()` - 上传图片
- `extractIngredients()` - 提取成分
- `getUserProducts()` - 获取用户产品列表
- `getProduct()` - 获取单个产品详情

### IngredientAnalysisApiService.swift
- `analyzeIngredients()` - 分析产品成分
- `getIngredientAnalysis()` - 获取成分分析结果

### ConflictApiService.swift
- `analyzeConflict()` - 分析产品冲突
- `getUserConflicts()` - 获取用户冲突记录
- `getConflict()` - 获取冲突详情

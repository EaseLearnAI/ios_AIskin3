## 使用说明

### iOS应用
1. 确保用户已登录（通过`AuthService`）
2. 在`SkinStatusView`中选择或拍摄图片
3. 点击分析按钮，应用会自动调用API
4. 分析完成后，结果会自动显示在UI中

### 测试脚本
```bash
cd doc
npm install  # 首次运行需要安装依赖
node 皮肤检测API测试.js
```

## 数据流

```
用户操作
  ↓
SkinStatusView
  ↓
SkinAnalysisApiService
  ↓
APIClient (网络请求)
  ↓
后端API
  ↓
响应数据
  ↓
convertToAnalysisResult (数据转换)
  ↓
AnalysisResult (UI格式)
  ↓
UI组件显示
```

## 注意事项

1. **认证**: 所有API调用都需要Bearer Token，通过`AuthService.shared.getToken()`获取
2. **错误处理**: 所有API调用都包含错误处理，失败时会显示错误提示
3. **数据转换**: API响应格式和UI显示格式不同，使用`convertToAnalysisResult()`进行转换
4. **异步操作**: 所有网络请求都是异步的，使用`async/await`处理
